AI Skills Reference

These are the Claude Code skills set up for the Autoeight project. Each one is a set of instructions that tells the AI exactly how to handle a specific type of task. Click any skill to see what it does and when to use it.

Brand Voice

How Autoeight sounds

Direct. Conversational. Confident but not arrogant. Like someone who's good at what they do and doesn't need to dress it up. We use contractions, mix short and long sentences, and avoid corporate jargon.

Banned words:

comprehensive streamlined robust holistic empower bespoke cutting-edge seamlessly leverage utilize facilitate innovative synergy

Don't write like this
"We leverage cutting-edge AI technology to deliver comprehensive, end-to-end automation solutions that empower businesses to streamline their operations."
Write like this
"We build AI systems that save your team hours every day. No fluff, just tools that actually work."
Marketing & Content Skills
Copywriting
Content
Write or rewrite website copy. Headlines, CTAs, service pages, landing pages.

When to use

Whenever you need to write new page copy, rewrite something that sounds off, or create a headline or CTA.

Trigger phrases

rewrite this copy make this sound better write a landing page homepage copy headline CTA

Key rules

  • Lead with the benefit, not the feature
  • One idea per paragraph, 2-3 sentences max
  • Use specific numbers over vague claims
  • One clear CTA per section
Cold Email
Sales
Write B2B outreach emails that sound human and get replies.

When to use

When you need to write cold outreach to prospects, follow-up sequences, or sales emails.

Key rules

  • Under 100 words per email
  • Reference something specific about the prospect
  • Never start with "I hope this finds you well"
  • One question CTA, low commitment
  • 4-email sequence: intro, proof point, shorter follow-up, break-up
Email Sequences
Automation
Design automated email flows. Welcome series, post-purchase, nurture, re-engagement.

Sequence types

  • Welcome: 4 emails over 8 days. Thanks, quick win, social proof, soft CTA.
  • Post-purchase: Confirmation, dispatch, check-in (day 5), review request (day 14).
  • Cold outreach: Personalised intro, proof (day 3), different angle (day 7), break-up (day 14).
  • Re-engagement: "Been a while" offer, social proof (day 4), final chance with deadline (day 10).

Key rules

  • Subject lines under 50 chars, no clickbait
  • First line must be useful, not "I hope this finds you well"
  • One CTA per email maximum

Case Study Writer
Content
Write client case studies with the right structure, KPIs, and tone.

Structure

  • Summary card with 3 key metrics
  • The Problem (who they are, what was broken)
  • What We Did (4 feature cards, outcome-focused)
  • The Result (story of the change + 4 metrics)

Key rules

  • No personal names in the body. Use "the team", "the business".
  • Focus on KPIs: time saved, cost reduced, leads generated
  • No tech stack or feature list sections
  • Each case study gets its own folder in brand_assets/case-studies/
Sales Enablement
Sales
Create pitch decks, one-pagers, proposals, and objection handling docs.

Materials

  • One-pager: Who we are, the problem, what we do, proof, CTA. One page max.
  • Proposal: Their problem, our approach, timeline, investment, next steps.
  • Objection handling: Too expensive, can do in-house, tried before, too small.

Key rules

  • Always lead with their pain, not our capabilities
  • Use case study numbers as proof
  • Write for the decision-maker, not the technical person
SEO & Technical Skills
SEO Audit
SEO
Run technical and on-page SEO audits. Check meta tags, schema, OG tags, headings, and more.

What it checks

  • Title tag, meta description, H1, heading hierarchy
  • Canonical URL, mobile viewport, HTTPS
  • JSON-LD structured data
  • Open Graph and Twitter Card tags
  • Image alt text, internal linking, URL structure
  • Local SEO: NAP, geo-coordinates, service areas

Output

Score out of 10, critical issues, quick wins, nice-to-haves, and what's already working.

Schema Markup
SEO
Add JSON-LD structured data so Google understands each page and can show rich results.

Schema types by page

  • Homepage: Organization + WebSite
  • Service pages: Service schema
  • Blog posts: Article + BreadcrumbList
  • Case studies: Article schema
  • About: Organization schema
Page CRO
Conversion
Analyse any page for conversion rate optimisation. Find what's stopping visitors from taking action.

What it checks

  • Above the fold: Is the value clear in 5 seconds?
  • Trust & social proof near CTAs
  • CTA clarity: specific text, visible, not competing with others
  • Friction points: too many form fields, slow load, dead-end sections
  • Content flow: Problem → Solution → Proof → CTA

Output

Score out of 10, top 3 changes, section-by-section walkthrough, quick wins.
