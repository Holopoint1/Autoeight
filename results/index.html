Matrix Learning Platform

Matrix's course workbooks lived in long Word documents. We built a learning platform that splits each workbook into individual worksheets and serves them as interactive courses. A course is defined in a simple Google Sheet, so a teacher can reorder worksheets, drop the ones they don't need, or pull sections from other courses into a new one, and the site updates itself. Learners get progress tracking, time logged, streaks and a certificate at completion.

  • Workbook splitterOne long document becomes individual, reusable worksheets
  • Sheet-driven course builderTeachers remix worksheets across courses without touching code
  • Progress, time and certificatesPer-worksheet completion, day streaks, certificate at 100%
  • One-click course downloadAny course compiled to a single Word or PDF, plus SCORM export
